## 任务

保持当前 HTML 中所有文本内容、数据结构、交互逻辑（编辑模式、标记完成/重点、折叠展开、标签导航、本地存储、弹窗详情、清单勾选）完全不变，仅对 CSS 视觉层与 DOM 结构排版进行彻底重构。

## 设计方向：复古旅行手账 · 实体剪贴簿风

### 1. 整体气质

- 模拟一本摊开的 2026 年实体旅行手账，页面有纸张纹理、胶带、邮票、邮戳、手写标注
- 参考 Moleskine 笔记本、复古航空邮件、Lonely Planet 旧版指南、日本旅行手账（トラベラーズノート）
- 数字页面要有"被翻阅过"的做旧感，但信息层级依然清晰

### 2. 色彩系统

- 背景：暖米色 `#f4f1ea`（像旧纸张），带细微的纸张噪点纹理（使用 base64 内联 SVG noise 或 CSS 渐变模拟）
- 主文字：`#2c241b`（深咖啡，非纯黑）
- 次级文字：`#8c7e6a`（暖灰褐）
- 强调色：复古航空蓝 `#2e5c8a`、邮戳红 `#c44d34`、牛皮纸棕 `#b8956a`
- 卡片背景：`#faf8f3`（象牙白），带 1px `#e8e0d4` 边框，阴影使用偏暖的 `0 4px 12px rgba(44,36,27,0.08)`
- 链接/交互：复古蓝 `#2e5c8a`，hover 时下划线为虚线

### 3. 字体排版

- 标题：使用 Google Fonts 引入 `Playfair Display`（衬线体，优雅复古感）+ 中文回退 `PingFang SC`
  - 页面主标题：42px，Playfair Display，字重 700，斜体，颜色 `#2c241b`
  - Section 标题：24px，Playfair Display，字重 600
- 正文：15px，`Inter` / `-apple-system` / `PingFang SC`，字重 400，行高 1.75，颜色 `#2c241b`
- 时间/数据：使用 `Caveat`（手写体）或 `JetBrains Mono`，营造手账标注感
  - 时间标签：18px，Caveat，颜色 `#c44d34`（像红色手账笔标注）
- 标签/徽章：使用小写或首字母大写，避免全大写，更符合手账感

### 4. 页面布局重构

- **整体容器**：最大宽度 960px（模拟 A4 手账摊开宽度），背景 `#f4f1ea`，四周留出像桌面的深色木纹或布料背景（使用 CSS 渐变模拟 `#e5ddd0` 到 `#d4c8b8`）
- **Hero 区域**：
  - 改为手账封面风格：一张泛黄的牛皮纸卡片，圆角 8px（模拟圆角器裁切），边缘有轻微不规则阴影
  - 左上角贴一张"航空邮件"贴纸（CSS 绘制：红蓝斜纹边框）
  - 标题使用 Playfair Display 斜体，下方用 Caveat 手写体标注 "2026.09.30 — 10.06"
  - 右上角盖一个红色圆形邮戳（CSS 绘制，文字"已确认 CONFIRMED"）
- **导航栏**：
  - 改为手账顶部标签页（Tab Index）：像文件夹标签一样，当前页标签为白色/象牙色突出，其他为浅褐色 recessed
  - 或使用横向排列的复古邮票形状按钮，当前项有"已盖邮戳"效果
- **概览指标**：
  - 改为 4 张"拍立得照片"风格卡片：白色边框（像照片白边），底部有手写标签（Caveat 字体）
  - 数值用大号衬线体，下方小字用手写体
  - 卡片微微旋转（-1deg, 1deg, -0.5deg, 1.5deg），像随意贴在页面上
- **机票区域（核心视觉）**：
  - 登机牌改为真实机票样式：米黄色纸张 `#f0e6d3`，顶部和底部有撕孔线（CSS 虚线或 radial-gradient 模拟圆孔）
  - 左侧有航空公司 Logo 区域（使用文字+简单几何图形模拟），右侧副联有"座位号"和"乘客姓名"
  - 增加"登机口 GATE"、"登机时间 BOARDING TIME"等复古航空元素
  - 两张机票用胶带（CSS 半透明黄色矩形，旋转 3deg）"贴"在页面上
- **日程导航**：
  - 改为手账侧边标签页：垂直排列在左侧，像笔记本的索引标签（Day 0 到 Day 5）
  - 每个标签为梯形或圆角矩形，突出页面边缘，当前标签为暖白色，其他为浅褐色
  - 标签文字使用手写体 + 小图标（飞机、火车、船、相机）
- **日程卡片（核心改动）**：
  - 每张日程卡片像一页手账内页：背景 `#faf8f3`，带极淡的横线（像笔记本纸，`repeating-linear-gradient` 模拟 28px 行高）
  - 顶部用和纸胶带（CSS 渐变：半透明米黄/浅绿/浅橙条带，旋转 -1deg）"粘"在页面上
  - 标题使用 Playfair Display + 日期用手写体 Caveat
  - 时间线改为手绘风格：左侧时间用红色手写体，连接线使用 2px 虚线（`border-left: 2px dashed #c44d34`），节点为手绘圆圈（非完美圆形，使用 slightly irregular border-radius）
  - 事件内容像手写笔记，但保持清晰可读
  - 标记重点：像用黄色荧光笔划过（`background: linear-gradient(transparent 60%, rgba(255,235,100,0.4) 60%)`）
  - 标记完成：像打勾（✓）+ 灰色删除线
  - 折叠展开：像翻页，按钮为圆形贴纸风格
- **信息卡片（Notes）**：
  - 改为 4 张"旅行备忘录"卡片，用不同颜色的和纸胶带贴在页面上
  - 每张卡片顶部有一个小图钉（CSS 绘制：圆形头部 + 细线针脚）
  - 图标改为手绘风格（使用 SVG stroke-linecap round，像钢笔速写）
- **预算表格**：
  - 改为手绘表格：边框使用 2px `#8c7e6a` 实线，表头背景 `#e8e0d4`
  - 总计行用粗体 + 底部双线边框（像账本）

### 5. 弹窗重构

- 弹窗改为"打开一本旅行笔记本"：
  - 背景：深褐色半透明遮罩 `rgba(44,36,27,0.6)` + 轻微模糊
  - 弹窗本体：A4 纸张样式，背景 `#faf8f3`，带纸张纹理，圆角 4px（模拟真实纸张）
  - 顶部有一条和纸胶带横跨固定
  - 左侧边缘有 3 个金属活页环（CSS 绘制：圆形+阴影，像活页夹）
  - 内容区：标题用 Playfair Display，详情用网格布局但边框为手绘虚线
  - 关闭按钮：右上角一个"×"手写风格，或像回形针别在页面上
  - 打开动画：从 0.9 缩放 + 轻微旋转（像从桌上拿起笔记本），0.4s 弹簧曲线
  - 大图区域像贴在笔记本上的照片，有白边和轻微旋转

### 6. 装饰元素（纯 CSS 绘制，不使用图片）

- **和纸胶带**：多处使用 `linear-gradient` 模拟半透明彩色胶带，旋转 1-3deg，"粘"在卡片顶部
- **邮戳**：圆形，红色 `#c44d34`，文字环绕，用于"已确认"、"已完成"状态
- **手绘圆圈/箭头**：用于标记重点，使用不规则 border-radius 或 SVG path
- **页脚**：像笔记本页码 "— Page 1 of 1 —"，居中，手写体

### 7. 动效与交互

- 所有过渡使用 `cubic-bezier(0.34, 1.56, 0.64, 1)`（略带弹性的弹簧感，像纸张弹动）
- 卡片 hover：轻微上浮 + 阴影加深，像纸张被拿起
- 点击：无机械涟漪，而是像按图钉一样轻微下压 `translateY(1px)`
- 页面滚动：无复杂视差，保持手账的"平面翻阅感"
- 编辑模式：可编辑区域显示像铅笔线框 `border: 2px dashed #b8956a`，而非科技蓝

### 8. 响应式

- 桌面端：最大宽度 920px，像摊开的笔记本
- 平板：单栏，侧边标签改为顶部横向滚动
- 手机：全宽，纸张白边减少，胶带装饰简化，弹窗几乎全屏（仅顶部保留活页环装饰）
