## 任务

保持当前 HTML 中所有文本内容、数据结构、交互逻辑（编辑模式、标记完成/重点、折叠展开、标签导航、本地存储、弹窗详情、清单勾选）完全不变，仅对 CSS 视觉层与 DOM 结构排版进行彻底重构。

## 设计方向：侘寂自然 · 日式极简风

### 1. 整体气质

- 参考 MUJI 无印良品、原研哉设计、日本铁路时刻表、京都町屋导览册
- 极度克制、安静、自然材质感，信息像被精心摆放在和室榻榻米上
- 色彩来自自然：米白、亚麻、陶土、竹青、墨黑
- 整体像一本摊开的日式旅行案内（指南），每一页都留有大量"间"（留白/呼吸空间）

### 2. 色彩系统

- 背景：暖米白 `#f7f5f0`（像未漂白的和纸），无渐变、无纹理、无装饰
- 主文字：墨黑 `#2b2b2b`（非纯黑，带微弱暖调）
- 次级文字：鼠色 `#8c8c8c`
- 强调色：
  - 竹青 `#6b8e6b`（用于时间、标签、完成状态，像竹子的颜色）
  - 陶土 `#c17f59`（用于重点标记、价格、警告）
  - 墨灰 `#4a4a4a`（用于边框、分割线）
- 卡片背景：纯白 `#ffffff`，无阴影（完全扁平），仅用 1px `#e0ddd5` 细线边框区分
- 边框：全部使用 1px `#e0ddd5` 实线，或极淡的虚线，绝不使用发光、渐变、圆角阴影

### 3. 字体排版

- 全局使用 `-apple-system`, `"Hiragino Sans GB"`, `"Noto Sans SC"`, `"PingFang SC"`, sans-serif
- 页面主标题：36px，字重 300（极细），字间距 `0.08em`，颜色 `#2b2b2b`，行高 1.4
  - 标题下方有一条 40px 宽的细线（1px `#e0ddd5`），像日式标题的"引き算"
- Section Kicker：10px，字重 400，字间距 `0.2em`，全大写，颜色 `#8c8c8c`，前缀加 `—`（破折号，非连字符）
- 正文：15px，字重 400，行高 2.0（极大的行高，像竖排和文的呼吸），颜色 `#2b2b2b`
- 时间/数据：14px，字重 500，`JetBrains Mono` 或等宽字体，颜色 `#6b8e6b`（竹青色）
- 标签/徽章：10px，字重 500，圆角 2px（极小圆角），背景 `#f0ede8`，文字 `#4a4a4a`，像和纸标签

### 4. 页面布局重构

- **整体容器**：最大宽度 720px（极窄，模拟日式书籍版心），居中，背景 `#f7f5f0`
  - 左右留白极大（桌面端两侧留白占 40%），强迫视线聚焦中央
- **Hero 区域**：
  - 高度 40vh，极简，无背景图
  - 中央偏上放置标题，使用超大细体字，下方是日期与旅行者信息，像书籍扉页
  - 标题下方居中放置一条细横线（1px，40px 宽），下方小字标注
  - 整体像和纸上的书法题签，安静、庄重
- **导航栏**：
  - 改为顶部极简文字导航，无背景、无阴影、无圆角、无胶囊
  - 仅是一排横向排列的文字链接，间距 32px
  - 当前项：下方有一条 1px 墨黑实线（像下划线），无颜色变化
  - 工具按钮：改为文字链接样式（"编辑" / "重置"），hover 时颜色从 `#8c8c8c` 变为 `#2b2b2b`
  - 导航与内容之间用 1px `#e0ddd5` 实线分隔
- **概览指标**：
  - 改为 4 列等宽的极简数据块，无卡片、无背景、无阴影、无圆角
  - 每个块仅包含：上方小字标签（10px，灰色），下方数值（28px，细体，墨黑）
  - 块与块之间用 1px 竖线 `#e0ddd5` 分隔（像日式表格）
  - 整体像铁路时刻表或温泉旅馆的价目表
- **机票区域**：
  - 登机牌改为"乘车券"风格：纯白背景，1px 边框，圆角 2px（几乎直角）
  - 信息横向排列，像日本新干线的指定席券：出发站 | 箭头 | 到达站，下方小字时间
  - 右侧副联用虚线分隔，像可撕下的存根
  - 无旋转、无阴影、无装饰，仅靠精确的排版对齐产生美感
  - 两张票上下排列，间距 24px
- **日程导航**：
  - 改为纵向列表（像目录页），而非横向卡片
  - 左侧是页码/编号（01, 02, 03...），右侧是 Day 标题，中间用虚线连接（像目录的引线）
  - 当前项：文字为墨黑，其余为灰色
  - 或改为顶部横向的极简文字列表，当前项下方有竹青色细线
- **日程卡片（核心改动）**：
  - 每张卡片：纯白背景，1px `#e0ddd5` 边框，圆角 2px，无阴影
  - 顶部标题区：左侧是 Day 编号（大号细体，如 `Day 02`），右侧是日期，中间大量留白
  - 标题下方有一条全宽细线（1px `#e0ddd5`），像和纸的折痕
  - 时间线事件：
    - 改为上下结构（非左右）：上方是时间（竹青色，14px），下方是内容
    - 事件之间用 24px 留白分隔，无连接线、无节点圆点
    - 或仅使用极淡的 1px 虚线分隔事件，像日记的分段
  - 标记重点：文字下方有一条陶土色的波浪线（使用 CSS `text-decoration: underline wavy #c17f59`），像手账的荧光标记
  - 标记完成：文字颜色变为 `#c0c0c0`，左侧有一个竹青色的小圆点（•），像已读标记
  - 折叠按钮：改为极简的 `＋` / `－` 符号，位于标题右侧，无背景、无圆角
- **信息卡片（Notes）**：
  - 改为 4 个无边框的文本块，仅用留白和细线分隔
  - 每个块顶部有一个小图标（极简线条，1px stroke，竹青色），下方是标题（14px，字重 600），再下方是列表
  - 列表项前缀使用 `·`（中点）或 `◦`（小圆），不使用实心圆点
  - 块与块之间用 1px 竖线或 48px 留白分隔
- **预算表格**：
  - 极简表格：表头下方一条 2px 墨黑实线，其余行仅用 1px 淡灰线分隔
  - 无背景色、无斑马纹、无圆角
  - 总计行：上方一条 2px 墨黑实线，文字加粗

### 5. 弹窗重构

- 弹窗改为"和纸便签"风格：
  - 背景遮罩：`rgba(247,245,240,0.9)`（暖白，非黑），无模糊或极淡模糊
  - 弹窗本体：纯白背景，1px `#e0ddd5` 边框，圆角 2px，无阴影
  - 顶部无关闭按钮（或仅在右上角有一个极小的 `×`）
  - 内容区：
    - 大图区域：16:9，纯白占位，像未贴照片的相框，边框 1px 淡灰
    - 标题：20px，字重 300，细体，墨黑
    - 详情：改为上下排列的文本段落，非网格卡片，像书信
    - 标签使用括号包裹（如 `(交通)` `(摄影)`），竹青色，等宽字体
  - 打开动画：从下方极轻微上浮（`translateY(8px)` → `translateY(0)`）+ 淡入，时长 0.4s，极缓的 ease-out
  - 关闭动画：淡出，时长 0.2s

### 6. 动效与交互

- 所有过渡使用 `ease-out`，时长 0.3s-0.5s，极缓、安静
- 页面滚动：无视差、无浮动、无动画，像翻阅纸质书
- 卡片 hover：无任何变化（保持扁平），或仅文字颜色从 `#8c8c8c` 变为 `#2b2b2b`
- 按钮点击：无缩放、无涟漪，仅颜色瞬间变化（像按和纸开关）
- 编辑模式：可编辑区域显示 1px 竹青色实线边框，无阴影、无背景变化
- 整体追求"无设计的设计"，动效越少越好，信息本身即是装饰

### 7. 响应式

- 桌面端：最大宽度 720px（版心），两侧大量留白，像书籍
- 平板：最大宽度 640px，留白减少
- 手机：
  - 最大宽度 100%，左右留白 20px
  - 导航栏改为顶部极简横向滚动文字
  - 日程卡片全宽，边框保留
  - 概览指标改为 2×2，用细线分隔
  - 弹窗全宽，上下留白 40px

### 8. 禁止修改

- 所有 JavaScript 逻辑、事件监听、localStorage 键名、数据结构保持不变
- 所有文本内容、图片路径、class 名（如需调整则必须保证 JS 选择器仍能命中）需兼容
- 编辑模式、标记完成/重点、折叠展开、清单勾选、标签导航、弹窗打开关闭的交互逻辑完全保留
