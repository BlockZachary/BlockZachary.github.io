Day 2 · 港岛线 / 维港摄影线

WEST KOWLOON → TSIM SHA TSUI → WAN CHAI → CENTRAL → KENNEDY TOWN · OCT 02

07:15
深圳北乘高铁赴香港至少提前 45—60 分钟到站；西九龙完成一地两检，早餐尽量在深圳解决。
09:15
西九龙 → 2 元纯净水店 → 重庆大厦街景抵港后先进入尖沙咀街区补给；按笔记定位核对店名与营业状态，顺拍弥敦道和重庆大厦外观，再向尖东方向前往 K11。
10:00
K11 MUSEA → 星光大道从 K11 接入海滨后一路向西，拍建筑线条、金像奖雕塑和维港；上午顺光，长焦可压缩港岛楼群。
11:00
文化中心 → 钟楼 → 海港城 / 1881文化中心几何墙、钟楼与小轮同框、1881 白色回廊；海港城只作午餐、洗手间和避暑点。
12:30
天星小轮（尖沙咀 → 湾仔）上层靠窗拍维港与人物侧影；先到最东端湾仔，再沿港岛线一路向西，不跨区折返。
13:00
湾仔海滨 → 中环 → 上环湾仔会展海滨起步，经中环码头、街市、半山扶梯与大馆，再到上环西港城；PMQ 视体力删除。
15:45
西营盘 → 香港大学 → 石塘咀西营盘正街斜坡、港大本部建筑与石塘咀旧街依次向西；坡道用长焦压缩，避免站入车道。
17:20
坚尼地城海旁日落 → 返回西九龙在公共海滨拍电车、街景与日落，不占居民入口；按已购车次倒推至少 90 分钟返程。

Day 3 · 九龙市井 / 港岛东摄影线

MONG KOK → YAU MA TEI → TSIM SHA TSUI → NORTH POINT → QUARRY BAY · OCT 03

08:00
深圳北 → 香港西九龙第二次香港签注；抵港后去旺角东，从北向南走，避免旺角—庙街之间来回折返。
09:30
花墟 → 雀鸟花园 → 金鱼街花墙、铁栏、旧楼与市场色彩适合人物街拍；店内和摊主近照先征得同意，雀鸟花园人多则快速通过。
11:00
花园街 → 女人街 → 旺角宝藏小店沿波鞋街、女人街向南，亚皆老街中心或信和中心只选 1—2 处；拍密集招牌，也为午餐留时间。
12:30
旺角午餐 → 果栏 → 油麻地警署午餐后继续向南；果栏只在公共道路拍环境，警署只看外观，不进入装卸区或受限区域。
14:15
庙街 → 佐敦 → 尖沙咀街道以庙街牌坊、弥敦道旧楼和重庆大厦周边街道为主，沿九龙半岛一路向南，不折返等夜市。
15:45
尖沙咀 → 北角乘港铁前往北角；北角春秧街拍电车穿过市集的生活感画面，使用长焦并与车辆保持安全距离。
17:00
鲗鱼涌怪兽大厦鲗鱼涌站 A 口步行前往益昌大厦内院；广角仰拍密集楼体，长焦拍几何窗格，安静拍摄并尊重居民。
18:15
港岛东晚餐 → 返回深圳北角或鲗鱼涌就近用餐，不回九龙补景点；按跨境车次预留至少 90 分钟前往西九龙。

BORDER GATE → GUIA → OLD TOWN → FISHERMAN'S WHARF · OCT 04

12:45
大三巴侧机位 → 恋爱巷避开正中主阶梯人潮，从侧巷、哪吒庙方向和恋爱巷取景；人物用长焦压缩彩色墙面。
14:00
澳门老城美食候选池葡挞、猪扒包、牛杂、虾子捞面、水蟹粥、云吞、咖喱、双皮奶、木糠布甸任选；热门店超过 20 分钟换同类。
15:00
玫瑰堂 → 议事亭前地教堂黄色立面、葡式波浪地砖、市政署回廊；广场过密时用窄巷与建筑局部拍人物。
17:15
渔人码头日落（可替换）用拱门框景拍人物和外港日落；若老城延误或天气差，直接回酒店休整，不额外追夜景项目。

Notes & Preparation

证件与通讯

  • 港澳通行证：香港 2 次签注 + 澳门 1 次签注。
  • 网络：支付宝境外流量包，或提前购买港澳通用卡。
  • 电源：英标转换插头、≤ 20000mAh 充电宝。

支付与现金

  • 港币：约 HK$500—800 / 人，覆盖小店与交通。
  • 澳门币：约 MOP$300—500 / 人；公交现金不找零。
  • 支付：微信 / 支付宝 + 银联卡，避免人民币 1:1 消费。

交通与拍摄提醒

  • 香港：游客全日通从首次入闸起连续 24 小时；当前成人 HK$75，不含高铁、机场快线、东铁头等/罗湖/落马洲。两天路线单日乘车不密集，现场算价后再买。
  • 澳门：公交正常票价 MOP$6；内地支付宝 / 微信乘车码可用但无车资及转乘优惠，准备零钱更稳。
  • 拍摄：港澳车辆靠左；不站车道、不占居民入口，商店、摊位及人物近照先征得同意。国庆优先人物与顺路线，不强求空镜。

紧急信息

  • 内地报警：110
  • 香港 / 澳门：999
  • 原则：证件随身、重要订单离线截图、保留返程缓冲。
