## 任务
保持当前 HTML 中所有文本内容、数据结构、交互逻辑（编辑模式、标记完成/重点、折叠展开、标签导航、本地存储、弹窗详情、清单勾选）完全不变，仅对 CSS 视觉层与 DOM 结构排版进行彻底重构。

## 设计方向：Apple Design · 空间杂志风

### 1. 整体气质
- 参考 Apple 官网、Apple Maps 指南、iOS 18 设计语言
- 极致留白、大字号标题、高信息密度但呼吸感极强
- 整体像一本可以交互的数字旅行杂志，而非传统的网页表单

### 2. 色彩系统
- 背景：从目前的浅蓝渐变改为 `#f5f5f7`（Apple 灰白）到 `#ffffff` 的极淡渐变，取消彩色光斑
- 主文字：`#1d1d1f`（Apple 近黑）
- 次级文字：`#86868b`（Apple 灰）
- 强调色：单一 `#0071e3`（Apple 蓝），取消多色渐变，保持克制
- 卡片背景：`rgba(255,255,255,0.72)` + `backdrop-filter: blur(20px) saturate(180%)`，呈现真正的 iOS 玻璃拟态
- 边框：极淡 `rgba(0,0,0,0.06)`，1px

### 3. 字体排版
- 全局使用 `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "PingFang SC", sans-serif`
- 页面主标题：`clamp(40px, 5vw, 72px)`，字重 700，字间距 `-0.02em`，行高 1.1
- Section Kicker：11px，字重 600，大写，字间距 `0.08em`，颜色 `#86868b`
- 正文：15px，字重 400，行高 1.6，颜色 `#1d1d1f`
- 数据/时间：13px，`SF Mono` / `JetBrains Mono`，字重 500
- 完全放弃目前的多处渐变文字，全部使用纯色

### 4. 页面布局重构
- **Hero 区域**：全宽通栏，高度 `70vh`，背景使用一张高质量的深圳/维港/澳门城市航拍图（带 30% 黑色渐变遮罩），文字左下角绝对定位。标题白色，副标题 `rgba(255,255,255,0.8)`。取消目前的彩色渐变 Hero。
- **导航栏**：改为顶部固定悬浮胶囊，背景 `rgba(255,255,255,0.8)` + `backdrop-filter: blur(20px)`，圆角 100px，高度 48px，阴影极淡。Tab 改为纯文字切换，无圆角按钮感，当前项下方有 2px `#0071e3` 指示条（带动画滑动）。
- **概览指标**：改为 4 列等宽卡片，不使用目前的错落网格。每张卡片高度一致，内部左对齐，数值使用超大字号（32px），标签在上方小字。卡片 hover 时轻微上浮 `translateY(-4px)` + 阴影加深。
- **机票区域**：登机牌改为 Apple Wallet 风格——圆角 16px，纯白背景，左侧主信息区，右侧撕票区用虚线分隔，无旋转角度，整齐排列（可横向滑动或上下堆叠）。阴影使用 `0 8px 24px rgba(0,0,0,0.08)`。
- **日程导航**：Day 导航改为横向滚动的胶囊标签栏，当前选中项为填充色 `#1d1d1f` 白字，其余为透明灰字。取消目前的卡片式 Day-nav。
- **日程卡片（核心改动）**：
  - 每张日程卡片改为全宽通栏卡片，圆角 24px，白色玻璃背景
  - 左侧增加一条 4px 的垂直色条作为时间轴（不同 Day 使用不同 pastel 色：Day1 淡蓝、Day2 淡绿、Day3 淡橙、Day4 淡紫、Day5 淡粉）
  - 时间线事件改为更清晰的左右结构：左侧固定宽度时间（14:00），右侧内容区。连接点改为实心圆点，悬停时放大。
  - 事件之间增加 24px 间距，避免拥挤
  - 折叠按钮改为右侧的圆形箭头按钮，旋转动画使用 `cubic-bezier(0.32, 0.72, 0, 1)`（Apple 弹簧曲线）
- **信息卡片（Notes）**：改为 2×2 网格，卡片圆角 20px，纯白，内部图标使用 Apple SF Symbols 风格细线图标（stroke-width 1.5），标题 15px 字重 600，列表文字 13px。

### 5. 弹窗重构
- 弹窗改为 iOS Sheet 风格：从底部滑入（`transform: translateY(100%)` → `translateY(0)`），圆角仅顶部 28px，背景 `rgba(255,255,255,0.95)` + 强模糊
- 关闭按钮在顶部中央：一条 36px 宽的灰色横线（iOS Grabber），下方才是内容
- 内容区：大图 16:9 圆角 16px，标题 22px 字重 700，详情网格改为单列大卡片，标签使用 pill 形状（圆角 100px，浅灰背景）
- 弹窗打开时，背后页面轻微缩放至 0.96 并变暗（`scale(0.96) brightness(0.8)`）

### 6. 动效与交互
- 所有过渡使用 `cubic-bezier(0.32, 0.72, 0, 1)`，时长 0.4s-0.5s
- 页面滚动时，Hero 图片产生视差效果（`background-attachment: fixed` 或 JS 控制 `translateY`）
- 卡片进入视口时，依次上浮淡入（stagger 0.08s）
- 按钮点击使用 Apple 风格的按压反馈：缩放至 0.97，无涟漪
- 编辑模式下，可编辑区域显示极淡的蓝色边框 `0 0 0 3px rgba(0,113,227,0.15)`，无阴影

### 7. 响应式
- 桌面端：最大宽度 1200px，左右留白 48px
- 平板：网格改为 2 列，日程时间线改为上下结构
- 手机：导航栏改为底部固定 Tab Bar（iOS 风格，5 个图标+文字），Hero 高度 50vh，日程卡片全宽无圆角（或 16px 圆角），弹窗全屏 Sheet

- 所有 JavaScript 逻辑、事件监听、localStorage 键名、数据结构保持不变
- 所有文本内容、图片路径、class 名（如需调整则必须保证 JS 选择器仍能命中）需兼容
